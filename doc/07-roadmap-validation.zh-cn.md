## 1. 调整后的路线

| 阶段 | 工作 | 出口条件 | 粗估 |
| --- | --- | --- | --- |

| E3 AI 工作流 | 通用 API 配置/SecretStorage、文本/图像/流/结构能力、候选关联/审阅/取消 | 两类兼容服务通过契约集合，提案可撤销，XML/JS 经引擎验证 | 2–3 人周 |

## 3. 编辑器验收矩阵

| 范围 | 必测项目 |
| --- | --- |
| 分镜 | 一格一幕、完整画面、重排不改路由/ID、复制新 ID、共享 visual 影响 |
| 往返 | 注释/空白/未知合法 JS 保留，Managed/Recognized/Opaque 分级，源行与对象映射 |
| 文档缓冲 | 文本与分镜同步、撤销/重做、未保存文件、外部编辑/多视图冲突、冻结快照 |
| 当前引擎 | 只接受 story 8/UI 3，类型/范围/隐藏选项/目标条件/历史/自循环/结束保持事务 |
| 资源 | 路径/符号链接/碰撞、同名替换失效、依赖、图集越界、点九标记与 density |
| 数据恢复 | 多文件提交日志、磁盘满/锁文件/崩溃、过期任务不得覆盖新稿 |
| 规模 | 合法预算内 100/1000 幕、多章节/大资源；虚拟分镜列表、有界缩略图/索引和取消 |
| 打包 | 依赖选择、许可证、显式附加、源变化、原子失败；模型/索引/存档不隐式加入 |

## 4. AI 服务验收

至少一个自部署本地兼容服务、一个远程兼容服务；每个记录 endpoint/profile revision、modelId、服务宣称/已探测能力。不得把“兼容 HTTP”推断成所有模型会看图或支持 schema。

使用确定性 mock 测试：无鉴权/密钥、模型列表缺失、文本/图片、SSE 分片、结构格式拒绝与降级、截断/坏 JSON、401/403/429/5xx、TLS、超时/取消、过期响应和重复重试。失败不写源码；密钥不进项目/日志/发行包，切换服务后不复用错误缓存。

冻结至少 100 个中文幕、200 个标注素材和 20 个无匹配样本；开发/留出集分开。建议目标为无效资源/非法路径 0、原台词保真、Top-3/无匹配识别各 ≥90%，同时报告 Top-1、人工修订和耗时；均为待确认规划阈值，不是实测保证。远程服务没有本机 VRAM 最低配置承诺，记录用户所选服务实际效果。

## 5. 调试和发行

IDE 适配器必须覆盖认证、请求去重、修订冲突、单次提交、提交前断点、隐藏选项/坏目标回滚、自循环、暂停时钟/输入阻挡、断线/超时后状态查询和渲染重建丢弃候选。状态是只读快照，不开放任意 jump/setVariables/eval。

真实 GUI 继续验证中文/16:9、补全/推进、菜单暂停、手动/自动槽跨进程、标题/媒体/模型；设备流与主观听感单列。KPAK 2 的实际大包用例、许可证/隐私清单、源码外运行不能只用小图单元测试替代。
