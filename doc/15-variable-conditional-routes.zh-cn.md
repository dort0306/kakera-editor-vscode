# 15 变量条件分流

0.5.4 增加自动选择后续幕的条件表单。使用播放器 v0.11.1 的同步 `frame("幕").advance/choice` 回调（旧 `on.*` 已删除），无需改变 XML 或引擎协议。

## 作者操作

1. 在工作台左侧“变量”中创建变量，例如 `hasKey`（bool）或 `trust`（int）。
2. 选择一幕，剧情路由设为“推进到下一幕”，点击“按变量条件分流”。选项幕也可在每个选项下分别设置。
3. 选择变量及比较方式、比较值、满足条件时进入的幕。
4. 设置“否则进入（默认线路）”；未连接可以保存，构建前必须连接。
5. 需要更多判断时点击“添加条件线路”，通过上移/下移调整优先级，然后“保存幕”。

布尔比较提供 true/false 下拉。整数支持等于、不等于、大小比较和“介于（含边界）”；范围上下限按十进制字符串输入，完整支持 i64。字符串仅支持等于/不等于。条件可通过“同时满足”“任一满足”组成且/或表达式。已识别的“非”（not）表达式可以显示和继续编辑内部条件。

## 运行语义

- 点击推进或选项后，先按顺序执行该回调的公共变量更新。
- 使用更新后的变量，从上到下检查条件，进入第一个满足条件的目标。
- 条件均不满足时，进入默认目标。条件可以重叠，优先级由顺序决定；编辑器不静态保证每条线路可达。
- 选项显示条件仍由引擎在选择前计算，与“选中后进入哪个幕”的分流独立。
- 条件不会在当前台词显示期间持续轮询或提前跳幕；在实际推进/选择时计算。
- 目标校验失败时，沿用引擎原有候选/提交行为，不由插件提前写入剧情变量。

布尔示例：`hasKey 等于 true → 开门`，默认进入“门被锁住”。整数示例：`trust 介于 0 至 29 → 陌生线路`，`trust 介于 30 至 69 → 普通线路`，默认进入“其他线路”。负数和范围外值走默认线路，除非作者另设规则。

对应 JS 示例：

```js
on.advance("gate", (ctx) => {
  ctx.add("trust", 1n);
  if ((ctx.vars["hasKey"] === true)) return "openDoor";
  if (((ctx.vars["trust"] >= 30n) && (ctx.vars["trust"] <= 69n))) return "normalRoute";
  return "otherRoute";
});
```

一次回调只有一份公共更新序列；不支持在每个条件分支内部设置独立副作用。需要分支专属更新时，在分支进入的后续幕设置更新。作者原有分支内部自定义语句保持原文、只读候选显示。

## 源码与流程图

领域 Route 增加 `branches: [{ when, target }]`；`target` 始终是默认目标。这是从当前 JS 缓冲提取的编辑模型，不是 sidecar 剧情数据库。每个条件最多 16 层表达式、每条路线最多 32 个条件分支。

支持类型化条件的 `if (...) return ...; return ...;`、`if/else-if/else` 和沿默认方向嵌套的三元表达式。只识别无副作用的条件及固定目标；共享函数、动态目标、任意函数判断、分支内更新和无明确默认返回仍保留 Opaque。

修改单一条件或目标时补丁对应语法节点；增减条件或修改公共更新时，只替换已识别回调的函数体，保留其中的作者注释、回调形式和其他源码。未改动的注册、辅助函数、UI 逻辑和文件保持原文。写入继续使用当前 TextDocument、revision 检查、冻结引擎验证、WorkspaceEdit 与本次文件保存。

图中每个条件及默认目标都有独立连接点和分色。拖线/断线只操作选中的出口，保留条件、优先级与公共更新；断线使用既有合法 End 占位。新增幕按条件顺序填首个未连接出口，然后才填默认出口；全部连接时不覆盖。删除分流幕不会替作者选择它的默认线路，原入边保留为待连接；删除其他幕时检查所有条件与默认入边。

SVG/HTML 导出保留各条件、默认目标与整数原值；已识别分流显示为确定的源码规则，实际命中仍取决于运行时变量。尚未识别的候选关系继续明确标记。

## 验证范围

单元与 React 测试覆盖生成/读取、局部补丁、Opaque 边界、布尔与范围表单、条件顺序、独立连线、占位和删除、导出以及 i64 类型约束。真实播放器测试在隔离工程中验证 true/false、首个匹配、区间端点、默认目标、公共更新后读取、超过 2^53 的精确比较及 i64 边界。
