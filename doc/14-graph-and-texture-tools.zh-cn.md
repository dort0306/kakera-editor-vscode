## 幕编辑交互

分支图维持默认的分支分色/同行布局，并允许作者拖动卡片定制位置。拖动中只更新本地视图，松手后按 10px 网格保存；Alt+方向键移动 20px。“自动排列”清空手动位置，缩放独立于布局。拖动和排序均不隐式修改路由。

每个实际幕左侧是输入点，右侧是推进或按 XML 顺序排列的选项输出点。拖动输出点或箭头终点到目标幕即可连线；也支持先选输出点再点击目标/输入点，Tab 和 Enter/空格完成键盘连接。Escape、指针取消或无效落点放弃操作。点击连线可将其断开。

改线根据幕和 option ID 定位受管/已识别注册，只修改 target；保留 option 文字、guard、有序 set/add 和其他代码。结束幕连接后转为推进，合法自循环允许存在。断线使用已有明确标记的合法 End 占位，不生成引擎不支持的空目标。自定义路由只读，不能绕过映射限制。草稿未保存、任务进行中或工作区未信任时不能修改。

布局以稳定 frame ID 保存于 `.editor/workbench.json`，无 ID 的旧幕暂按 ref。使用 WorkspaceEdit、定向保存和宿主撤销/重做；首次操作先建立空布局，再记录位置变化，使一次撤销回到空布局而不删除布局文件。布局不进入运行时剧情，源码内容验证不会因手动位置产生另一套路由。

## 流程图导出（0.5.1）

分支图工具栏提供“导出流程图”，通过保存对话框选择 SVG 或 HTML。导出全图而不是当前可见矩形，忽略屏幕缩放与搜索过滤，保留已保存或源码缓冲中的布局、分支颜色、循环/汇合、选项文字，以及待连接/未知/未接入入口的标记。未提交的表单草稿或进行中的拖线需先处理。

SVG 使用纯矢量节点、文字和连线，复用编辑器连线几何，不含 foreignObject、脚本、图片或外部资源；卡片/连线显示简要文字，悬停 title 保留全文，并为循环回线留边距。HTML 离线内嵌 SVG，附完整台词/选项/条件/有序更新清单和内部跳转，使用浏览器缩放、Ctrl+F 浏览，无需联网或脚本。

宿主根据当前 TextDocument 和布局生成，不接收 Webview 提供的任意 SVG/HTML。全部作者文字转义，HTML 使用禁止外部资源与脚本的 CSP。复查源 revision、目标文件指纹和未保存目标编辑，拒绝覆盖声明源码或资源；先写目标目录临时文件再替换，失败清理临时文件，旧导出尽量保留。未信任工作区不允许导出写入。候选动态关系仍需实际试玩确认。

导出预算为 2000 幕、10000 条候选路线、32MiB 文件；不宣称完成大型工程性能验收。SVG/HTML 使用系统字体，跨浏览器/矢量软件外观仍需按实际环境核对。

## 点九图

输入为已导入的普通 PNG/JPEG 或 nine-patch 资源。普通图片新增透明 1px 边框，已有点九先解析并移除旧标记边框，防止反复套边。

- 上边为水平伸缩段，左边为垂直伸缩段，每轴 1–8 段；坐标左闭右开，段之间至少有一个非标记像素。
- 下边为内容区横段，右边为内容区纵段；本工具写入一个明确内容矩形。读取缺省标记时沿用引擎的首尾伸缩段包围规则。
- 标记使用不透明纯黑，其他边框透明，四角不写黑点；内部 RGBA 像素保持不变。
- 画布框选和数字字段双向更新，显示伸缩段、内容框及不同目标尺寸的切片拉伸预览。预览沿用 `image_layout::axis` 的固定段、伸缩比例和小尺寸收缩规则。
- density 范围 0.125–8，属于 UI nine-patch 控件。可应用到既有专用控件或向选定页面添加示例节点；不把普通 image 冒充点九。

保存创建真实 PNG 文件并注册/更新 nine-patch 声明，通过真实引擎检查后保存对应 XML。既有点九的资源 ID 保持不变，src 指向新的 UUID 文件；旧文件保留以支持恢复。

## 图集生成与区域编辑

已有图集仍是普通 image。画布可选择/拖出矩形，编辑 name/x/y/width/height；点击只选择区域，不会把区域改成单像素。网格生成支持格子大小、间隙和四边相同边距，只保留完整格子。每个图集最多 256 个命名区域，名称唯一、宽高正、矩形不得越界；区域允许重叠，以支持状态或局部复用。

多图生成采用确定性的按行放置，保持选择顺序，不旋转、不裁去透明边；留指定透明间距。输出一张普通 PNG 和对应区域预设，保留所有源图。暂不提供自动紧密装箱、旋转/trim 或图集间像素绘画工具。

区域预设存于编辑器 sidecar，实际应用将 image 和 `region="x,y,width,height"` 写入所选 image/panel/button 节点；该控件既有 image-bind/region-bind 会按明确选择解除，其他节点及子节点保留。页面可以追加示例 image。运行时只依赖图片和真实 UI XML，不依赖区域预设，也不为每格生成发行图片。

## 后台处理、并发和恢复

PNG/JPEG 解析与 PNG 生成在独立 Worker 执行，不在 Webview 接收任意路径或任意文件字节。宿主根据已声明 asset ID、安全 ContentPath 读取资源，预览走私有缓存和 CSP 限定 URI。

单源文件最多 8MiB、边长 4096、总计 4M 像素（生成点九时还需容纳 2px 边框）；多图最多 64 张、输入总计 32MiB/8M 像素，输出不超过 4M 像素/8MiB。Worker 设置 256MiB JS 堆预算和 30 秒时限，取消终止该线程；Buffer 内存另受像素/文件预算限制。PNG 在解码前检查尺寸，Adam7 流另限解压输出。

打开图片记录内容哈希，保存与生成前后复查源图片；源改变要求重新打开。源文档沿用 revision、文档版本、冻结校验与 WorkspaceEdit 提交流程，保存只涉及本次文件。生成到新的 UUID 路径，不覆盖旧二进制；失败仅清理能够确认未被当前缓冲引用的新文件。

布局和图集预设只保存视图信息，不进入冻结内容或发行包。UI XML 与图片是运行时事实来源。当前仍不是整工程磁盘原子事务；完整磁盘满/崩溃恢复矩阵与大工程性能验收留待补齐。
