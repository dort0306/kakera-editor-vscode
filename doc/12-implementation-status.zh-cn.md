## 本轮已执行的检查

环境：Windows x64，Node.js 24.17.0、npm 12.2.0；VS Code 1.142.0（commit `6d62b1d5dace93a33b3a6d3eca1317bd5e15bcb1`）。清单声明最低 VS Code 1.100.0，但尚未在该最低版本复测。

引擎从开发机现有 Kakera v0.8.3 源码及 release 工具核对，未修改上游。模板 UI、资源/字体和 CLI 与实际 loader/接口比对后由真实工具校验。工具二进制的 SHA-256 由 `resources/tools/win32-x64/tools.json` 记录，不硬编码开发机绝对路径。

- `npm run typecheck`：通过。
- `npm test`：15 项通过；覆盖 CRLF/emoji/CDATA 和注释保留、未变表单字段逐字保真、复制/排序 ID、Opaque、i64 边界、路由错误、路径/联接、未保存快照、AI HTTP/SSE/拒绝输出、JSON Lines ID/修订/失败后状态刷新。
- `npm run test:integration`：真实播放器校验模板和含未保存台词的代次；KPAK 1/2 打包与全包检查通过；确认未引用原稿不入包、字体许可证入包；复制播放器到发行根，以默认邻近包完成独立全包检查。
- `npm run test:host`：真实 VS Code 激活、未保存 TextDocument、冻结校验、旧 revision 拒绝、单文件及有效多文件 undo/redo、无效多文件候选不提交、多 Custom Editor 视图；通过真实播放器执行 inline DAP 启动、配置、断点、栈/源码/变量、候选提交前状态、自循环及变量单次提交、拒绝 evaluate、断开与清理。第二个真实受限工作区验证只读激活、修改被拒、未执行工具或写入项目元数据。
- `npm run package`：生成内部离线 VSIX，采用显式文件白名单；不包含 node_modules、测试工作区、AI 凭据或原稿。包中包含工具与字体。
- 使用 VS Code CLI 将最终 VSIX 安装到 `.test-work/installed-extensions` 与隔离用户数据目录，安装成功；扩展列表报告 `dort0306.kakera-editor-vscode@0.1.0`，没有修改日常扩展环境。

本地协议与宿主测试需要 loopback 连接；受限执行沙箱阻止时使用具备相应权限的测试环境运行。mock 验证仅代表客户端契约，不代表已连接任何真实 AI 服务。

## 尚未完成或未验收

- 未完成所有 E0–E5 出口；尤其最低宿主版本矩阵、100/1000 幕性能测量、磁盘满/进程崩溃的完整恢复故障注入尚未验收。当前 journal 是可检查的前后内容恢复记录，不能声称整工程磁盘原子事务或自动三方合并。
- Rust 独立结构化内容工具未实现；直接复用已存在的播放器/打包器 CLI，完整校验日志仍是文本，不伪造 JSON 诊断或源码行号。
- JS 的 Recognized 局部编辑、任意组合条件的可视表单、目标条件分支列表、单个受管文件部分接管尚未开放。组合表达式可由受管编译器往返，但 UI 只提供简单变量比较；高级逻辑使用源码。
- 图集/点九/模型/视频的专用可视工具、资源批量替换/重命名/删除、完整 UI/动态引用图尚未交付。现有声明保持原文，最终由引擎校验。
- 静态图片预览只准备当前画面使用的普通图片，单文件限 8MiB；没有声称与 D3D11/媒体/Live2D 渲染完全一致。分镜采用每批 50 幕的有界分页，未声称已实现连续虚拟滚动。
- AI 当前只做纯文本拆幕；图片、资源关联、结构输出能力探测、多个服务 profile、自动重试/修复、真实本地/远程服务和冻结中文集合评估尚未完成。未配置的服务不自动连接。
- DAP 为帧级适配；条件断点、JS 调用栈/求值/行级步进、任意跳转或写变量均不提供。完整路线录制/重放、断线去重缓存重发与渲染重建全矩阵尚未验收；当前不自动重试控制命令。
- 游戏构建 UI 当前使用 KPAK 2；格式 1 已通过底层工具集成测试，尚未作为 UI 选项开放。大包上限、设备音轨、主观听感、复杂存档兼容及全媒体 GUI 测试未在本轮覆盖。
- 没有附带 Live2D Core 或第三方模型，不宣称完整模型发行支持。没有公开发布 Marketplace 或上传游戏；对外发行前仍需完成完整供应依赖审计与签名/发布流程。

后续优先补齐版本/信任矩阵和恢复故障注入，再按设计扩展资源、AI 能力探测与路线回放；已有可用功能不能替代这些尚未完成的验收。
